## `0x01` About

Backend developer and Software Engineering student at **[INATEL](https://inatel.br/home/)**, graduating in December 2026. I build APIs, integrations and distributed systems in **Java (Spring Boot)**, **TypeScript (Node.js, NestJS)**, **Go** and **Python (Django, Flask, FastAPI)**.

Currently a Systems intern at **Midea Group**, working on finance and tax system requirements, writing SQL and PL/SQL to trace inconsistencies across integrated modules, and Python scripts to automate internal processes, in English with an international team.

Interested in economics and financial markets, in both centralized and decentralized finance. I study the subject independently, including technical analysis and crypto assets.
